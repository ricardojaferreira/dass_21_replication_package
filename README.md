## Statistical analysis on depression, anxiety and stress scales (DASS21)

This repository contains the code and data used to replicate the statistical analysis of the DASS21 dataset. 
The analysis was performed using python and Jupyter Notebooks.

The repository is organized as follows:


 - **/data_analysis**: Contains the Jupyter notebooks used to conduct the statistical analyses presented in this work:

   - __demographic_overview.ipynb__ – Generates the demographic profile discussed in the introduction.

   - __anova.ipynb__ – Performs the One-Way ANOVA analysis.

   - __exploratory_factor_analysis.ipynb__ – Runs the exploratory factor analysis.

   - __cluster_analysis.ipynb__ – Implements the clustering analysis.
   - This folder also includes the dataset used throughout the analyses: __BD_MI_II_2024_25.sav.

- **/figures**: Contains the figures generated by the analysis scripts. Each subfolder corresponds to a specific analysis section: __demographic_analysis__, __anova__, __efa__, and __cluster__.
    
- **Root directory**: Includes a PDF version of the analysis report, __Statistical_analysis_on_depression__anxiety_and_stress_scales__DASS_21.pdf__,
